# Что есть сейчас

## Текущее состояние прототипа

### Реализовано

- Базовая физическая модель, спроектирвованная так, что позволяет расширять себя практически бесконечно вплоть до грузовиков и мотоциклов
- Есть альфа прототип клиента игры с возможность провести тестовые заезды
- Есть программа, позволяющая создавать двигатели по деталям: блок, цилиндры, коленвал, тип топлива, трубина или нагнетатель.
Функционал этого инструмента будет использован в движке игры. Ниже скриншот из Excel, который был ранним прототипом программы расчета авто.

- Сетевое взаимодействие между клиентом и сервером
- Прототип сервера, который хранит и отдает пользователя и список его авто
- Инструмент для настройки и тестирования автомобиля

### Имеющиеся ресурсы
- Есть графика для нескольких автомобилей, которые будут представлены в игре
- Есть два разработчика, погруженные в проект
- Есть ранняя версия UI (интерфейса игры)
- Есть мощности для тестирования будущего рабочего прототипа
